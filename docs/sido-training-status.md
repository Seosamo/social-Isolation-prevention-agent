# 서울·강원 한정 학습 상태

현재 기본 방법은 비지도 Isolation Forest이며 실제 학습·이후 월 점수 산출을 완료했다. 최신 모델·후보 수·실행법은 [활동 위축 이상 탐지](activity-anomaly-model.md)를 참고한다. 아래 내용은 보존된 지도학습 실험의 준비 상태와 양성 라벨 부재에 관한 기록이다.

2026-10-20 실제 로컬 자료를 실행한 결과다.

## 범위와 공간 연결

- 대상: 서울특별시와 강원특별자치도. `region_codes=["11","32"]`이며 코드는 SGIS 경계의 코드 체계다.
- 서울 소지역 2,035개와 강원 소지역 747개, 총 2,782개를 사용한다.
- 경기 6개 및 판정 보류 11개 소지역, 총 17개는 분석 파이프라인에서 제외한다.
- 분석 단위는 시도·성·연령·월이다. 다른 시도를 학습·검증·테스트에 넣지 않는다.
- 원자료는 시도에 연결된 관측 격자 범위다. 시도 전체의 유동이나 전국을 대표하는 관측이라고 해석하지 않는다.

공공데이터포털의 [공식 SGIS 행정구역 경계](https://www.data.go.kr/data/15129688/fileData.do) 중 2025-06-30 기준 시도 경계를 사용한다. 경계 PRJ는 EPSG:5179다. SKT 설명서는 UTM-K만 명시하므로 EPSG:5179와 EPSG:5178로 각각 해석하고, 모든 월·자료 유형에서 동일 소지역의 모든 좌표가 같은 시도로 판정된 경우만 채택한다. 경계가 불명확한 소지역은 보류한다.

이 연결은 원본 측지계를 확정한 것이 아니다. 후보 파일의 `verified=false`를 유지하면서 설정의 `mapping_mode=crs_consensus`로 사용을 명시한다. 코드·시도명이 검증된 지리 코드표와, 좌표에서 추론한 소지역 연결표를 구분한다. 감사 보고서에 기록된 후보 CSV·정제 목록 해시가 일치해야 사용할 수 있다.

## 라벨과 학습 방향

- 최소 구조 참조 지역과 학습 지역을 각각 2개로 설정한다. 반복 월·성·연령 행을 추가 시도로 세지 않는다.
- 구조 기준 S는 같은 성·연령의 1인가구 구성비를 두 시도 사이에서 비교한다. 75% 분위수는 이 두 시도의 상대 기준이며 전국 상위 25%나 검증된 고립 기준이 아니다.
- 유동 위축 A 및 낮·주말 보조 근거 B는 두 연속 비교를 사용한다. 20% 감소·10% 안정 조건을 유지한다.
- A·S·B가 모두 support면 양성, A·B가 안정적이고 S를 판정할 수 있으면 음성, 나머지는 라벨 판단 보류다. 라벨 판단 보류를 음성으로 채우지 않는다.
- 공간 판정 보류 소지역은 집계에서 제외하지만, 포함된 서울·강원 안의 자료 부족·상충에 따른 라벨 판단 보류는 보존한다.
- 일부 시군구 카드 자료는 시도 전체 소비로 사용하지 않는다.
- 2024년 고독사 통계는 배경 설명에만 쓰고 라벨·학습 입력에서 제외한다.

## 실제 실행 결과

| 구분 | 결과 |
| --- | --- |
| 분석 표본 | 144행: 두 시도 × 성별 2개 × 연령 6개 × 6개월 |
| 정확히 대응하는 구조 근거 | 120행 |
| 구조 근거 불일치 | 24행: SKT 10대와 구조 통계 20세 미만을 임의 결합하지 않음 |
| 학습: 2025년 10월까지 | 음성 18행, 양성 0행 |
| 검증: 2025년 11월 | 음성 19행, 양성 0행 |
| 테스트: 2025년 12월 | 음성 20행, 양성 0행 |
| 전체 라벨 | 음성 57행, 판단 보류 87행, 양성 0행 |
| 분류 학습 | 양성·음성이 모두 있어야 하므로 중단 |

현재 남은 차단 사유는 학습 양성 라벨 부재다. 공간 연결과 두 지역 학습 조건은 통과했다. 양성·음성 분류기를 이 데이터로 학습했다고 보고할 수 없다. 기존 모델 파일은 보존하며 가짜 양성이나 임의 임계값 변경으로 학습을 통과시키지 않는다.

평가는 같은 두 시도의 이후 월에 한정한다. 다른 시도로의 일반화나 당시 실시간 예측 성능을 주장하지 않는다. 향후 학습이 가능해지면 평가 결과에 시도별 성능을 함께 기록하고, 모델에는 학습 지역 범위를 저장해 범위 밖 지역의 예측을 보류한다.

## 재실행과 산출물

```powershell
.venv/Scripts/python.exe -B -m activity_agent spatial-audit --boundary-file data/boundaries/sido_2025/bnd_sido_00_2025_2Q.shp
.venv/Scripts/python.exe -B -m activity_agent run-isolation
```

`artifacts/isolation/spatial_audit.json`과 `block_geography_candidates.csv`는 전체 좌표 감사 기록이다. 학습에 사용되는 선택 범위는 `spatial_selection.json`, `cohort_manifest.json`, `readiness.json`에 별도로 기록된다. `labels.parquet`, `label_summary.json`, `label_reference.json`에 새 범위의 라벨·구조 기준이 저장된다. 원자료를 삭제할 필요는 없다.
