# 고립 의심 라벨링과 지도학습 확장 설계

상태: 별도 고립 의심 과제로 구현됨. 기존 활동 라벨·모델은 보존하며 실행법은 README의 확장 파이프라인 절을 참고한다.

현재 기본 학습은 정답 라벨이 필요 없는 [활동 위축 이상 탐지](activity-anomaly-model.md)로 전환했다. 아래 A·S·B 라벨과 지도학습 설계는 `isolation.method=supervised`로 선택하는 비교 실험이다. 기본 비지도 모델의 준비 상태나 점수를 기존 라벨 분류의 양성·음성 기준으로 해석하지 않는다.

2026-10-20 변경: 기본 분석 단위는 시도(`sido`), 기본 범위는 서울·강원 두 시도다. 경기 및 공간 판정 보류 소지역은 제외한다. `mapping_mode=crs_consensus`는 공식 2025년 경계와 두 UTM-K 후보에서 모든 관측 좌표의 시도 판정이 일치하는 소지역만 채택하는 실험 모드다. 원본 측지계가 검증됐다고 표시하지 않는다. 구조 기준 최소 참조 지역과 최소 학습 지역은 각각 2개이며, 구조 기준은 두 시도의 상대 비교다. 평가는 두 시도 안에서 시간으로 분리하고 다른 시도 일반화 성능으로 보고하지 않는다. 아래 시군구·행정동 조건은 해당 모드를 선택할 때 적용한다. 시군구 일부 카드 자료를 시도 전체 소비로 사용하지 않는다. 지역·월·성·연령의 반복 행은 독립 지역 수가 아니다. 현재 실제 라벨은 양성 0행으로 분류 학습이 중단됐으며 [실행 상태](sido-training-status.md)를 따른다.

## 목적과 권장 기본 방향

- 목표는 지역·성·연령 집단의 고립 의심 상태 판정이다. 개인 진단이나 고독사 발생 예측과 구분한다.
- 권장 학습 범위는 SKT와 구조 통계가 검증된 공간 매핑으로 연결되는 지역이다. 카드 관측이 있는 강남·춘천에서는 소비 근거를 추가한다. 카드가 없는 지역의 값을 0으로 채우지 않는다.
- 권장 첫 실험은 2025년 자료의 사후 분석이다. 연간 구조 통계를 사용한 결과를 2025년 당시의 실시간 예측 성능으로 보고하지 않는다.
- 기본값은 서울·강원 두 시도와 `retrospective`다. 두 지역의 관측 격자에 한정하며 다른 지역 일반화 성능을 주장하지 않는다.
- 2024년 고독사 통계는 `background_context`로만 저장한다. 라벨 규칙, 모델 입력, 판정 임계값 결정에는 넣지 않는다.

## 현재 입력 자료와 준비 상태

| 입력 | 확인된 범위 | 처리 |
| --- | --- | --- |
| SKT·카드 | 2025년 7~12월 | 기존 정제·품질 처리 재사용 |
| 독거노인 현황 | 2025년 서울 동별·성별, 65세 이상 | 경제적 취약성 지표; 다른 연령대에 적용하지 않음 |
| 독거노인가구비율 | 2025년 시군구, 전체 일반가구 분모 | 고령층 지역 맥락; 해당 성·연령의 독거 비율로 표현하지 않음 |
| 성·연령별 1인가구 | 현재 파일에는 전국·시도와 동부/읍부/면부만 존재 | 시군구 선택 자료 수급 전에는 시군구 집단 라벨 근거로 사용하지 않음 |
| 주민등록세대수 | 2025년 월별 시군구 | 지역 규모 변화 설명; 일반가구 분모로 대체하지 않음 |
| 고독사 발생 현황 | 2024년 17개 시도 | 과거 배경 정보로만 표시 |
| 공간 참조표 | 서울·강원 지리 코드와 좌표 합의 후보 존재 | 시도 실험은 명시적 `crs_consensus` 모드로 서울·강원만 채택 |

시군구 성·연령 1인가구 수·구성비는 대응 자료만 있으면 계산할 수 있다. 같은 성·연령의 전체 인구 대비 비율은 별도의 인구 자료와 조사 범위 확인이 필요하며 첫 버전의 필수 조건으로 두지 않는다.

## 데이터 계약과 공간·시간 결합

1. 표준 분석 키는 `(geo_level, geo_code, sex, age_band, month)`이다. 시도·시군구·행정동 모델을 별도로 학습하고 한 학습 표에 혼합하지 않는다.
2. 구조 자료는 긴 형식으로 정규화한다: `source_id, reference_period, available_at, geo_level, geo_code, sex, age_band, metric, value, denominator_kind, quality`.
3. 원본 지역명·단위·출처·해시를 보존한다. 지역명만으로 조인하지 않고 상위 지역과 기준 연도의 행정구역 코드를 함께 확인한다. 소계와 하위 행은 중복 합산하지 않는다.
4. 같은 단위의 자료는 키로 일대일 결합한다. 상위 지역 자료는 접미사 `_context`로 구분하고 자체적인 동·성·연령 관측치처럼 사용하지 않는다.
5. 동별 65세 이상과 SKT 60세 이상은 정확히 일치하지 않는다. 해당 자료는 연령 불일치를 표시한 고령층 맥락으로만 연결하며, 일치하는 구조 근거로 취급하지 않는다.
6. `20세 미만`을 임의로 10대로 분할하지 않는다. 정확히 구성 가능한 20·30·40·50대와 60세 이상은 합산하고, 불일치 구간은 구조 근거 부족으로 기록한다.
7. `retrospective` 모드에서는 기준 연도가 맞는 연간 통계를 설명용으로 연결하되 미래 예측 성능을 주장하지 않는다. `as_of` 모드는 `available_at <= decision_at` 조건을 강제한다. 공표일 미확인은 당시 이용 불가로 처리한다.
8. 판정 시점까지의 활동만 사용한다. `t월` 판정에 `t+1월` 활동을 사용하지 않는다. 다음 달 예측을 별도 과제로 만들 때는 목표와 입력 종료 시점을 새로 정의한다.

## 근거 생성과 약한 라벨

기존 `activity_decline_v1`과 새 `regional_isolation_suspicion_v1`을 별도 과제로 관리한다. 기존 활동 라벨을 고립 의심으로 이름만 바꾸지 않는다.

각 근거는 `support / against / abstain`과 이유·자료 범위를 반환한다.

- `A / 개인집단 유동 위축`: 동일 지역·성·연령의 유동 감소가 두 연속 비교에서 각각 20% 이상이면 support. 두 비교 모두 ±10%이면 against. 품질 부족·중간 범위는 abstain.
- `S / 구조적 취약성`: 현재 구현은 정확히 대응하는 지역·성·연령의 1인가구 구성비를 사용한다. 65세 이상 경제적 취약성은 SKT 60세 이상과 일치하지 않아 맥락으로만 보존한다. 높은 값이 곧 고립을 뜻하지 않는다. 학습 지역·기준 기간의 75% 분위수를 적합하고 평가 자료에는 고정한다. 서울·강원 실험에서는 두 시도의 상대 비교이며 전국 상위 25%가 아니다. 연간 자료를 월별로 반복 연결해도 기준 분포에는 원래 지역·대상·기준 기간별 한 번만 반영한다. 최소 2개 지역·서로 다른 값이 없는 참조 집단에서는 abstain한다. 이는 통계적 타당성을 보장하는 표본 크기가 아니다.
- `B / 활동 보조 근거`: 지역 전체 낮·주말 감소 또는 시군구 사회/여가 소비 감소. 두 연속 비교에서 각각 20% 이상이면 support, 두 비교 모두 ±10%이면 against다. 지역·대상 범위를 보존한다. 유동 근거와 독립적인 측정이라고 주장하지 않는다.
- `D / 고독사 배경`: 출력 설명용이다. A/S/B 판정에 참여하지 않는다.

| 조건 | 약한 라벨 |
| --- | --- |
| A=support, S=support, 적용 가능한 B 중 하나 이상=support | 1: 고립 의심 |
| A=against, S를 판정할 자료가 있고, 적용 가능한 B가 하나 이상 관측되며 모두 안정 범위 | 0: 의심 근거 미약 |
| 필수 근거 누락, 상충, 품질 문제 또는 중간 구간 | -1: 판단 보류 |

S가 높더라도 활동이 안정적이면 고립 부재를 확인한 것으로 표현하지 않는다. B가 전부 누락되면 0으로 만들지 않는다. 시군구 카드 근거를 동별 직접 소비 관측으로 복제하지 않는다. 카드 없는 지역은 같은 단위의 시간대·요일 근거를 사용할 수 있다.

위 기준은 검증된 임상·행정 판정 기준이 아닌 초기 약한 감독 규칙이다. 현재 자료·연령 범위로 S를 구성할 수 없는 표본은 새 과제의 라벨을 보류한다. 기존 활동 분석은 계속 제공한다.

## 코드 구성과 인터페이스

기존 `features`, `labels`, `modeling`과 대시보드 조회 구조를 재사용하고 아래 모듈을 추가한다.

| 모듈 | 책임 |
| --- | --- |
| `isolation/structural.py` | CSV별 다중 헤더·인코딩 처리, 표준화, 합계·분모 검증 |
| `isolation/cohorts.py` | 공간·연령·시점 정합화와 분석 표본 구성 |
| `isolation/labeling.py` | 근거 함수, 학습 기준 분포 적합, 라벨 결합과 설명 |
| `isolation/training.py` | 새 과제 데이터셋, 학습 전 점검, 모델·평가·버전 저장 |

공통 집계는 `data/aggregation.py`, 과제 공통 평가와 저장은 `common/`, 화면은 `ui/`에 둔다. 고립 의심 모듈이 활동 학습 모듈의 평가 함수를 가져오는 의존성은 두지 않는다.

주요 호출 순서는 다음과 같다.

```python
sources = load_structural_sources(config)
readiness = validate_training_readiness(sources, spatial_mapping, config)
cohorts = build_cohorts(activity_features, sources, spatial_mapping, config)
train, validation, test = split_cohorts(cohorts, split_spec)

policy = IsolationLabelPolicy(config.labeling)
policy.fit_reference(train)              # 분위수 등은 학습 자료에서만 고정
train_labels = policy.label(train)
validation_labels = policy.label(validation)
test_labels = policy.label(test)

model = train_model(train, train_labels, config.training)
evaluation = evaluate_model(model, validation, test, validation_labels, test_labels)
```

`ReadinessReport`는 사용 가능한 과제·지역·연령, 결합률, 라벨 보류 사유, 독립 지역 수, 학습 가능 여부를 반환한다. 부족한 자료를 0으로 보충해 준비 상태를 통과시키지 않는다.

## 라벨 저장소와 모델

- SQLite에 새 과제용 `label_sets`, `label_decisions`, `label_reviews`를 추가한다. 기존 테이블·이력을 유지한다.
- 식별자는 `task_id + cohort_id + feature_version + label_version`이다. 약한 규칙·수동 검토·독립 외부 확인을 구분한다.
- 학습 모델은 우선 기존의 결측 대체·표준화·클래스 가중 로지스틱 회귀를 재사용한다. 전처리는 학습 표본에만 적합한다.
- 입력은 명시적 허용 목록으로 정한다. 라벨, 근거의 support/against 결과, 규칙 합산값, 검토 텍스트, 고독사 통계는 제외한다. 라벨 구성에 쓰인 원지표를 사용할 경우 결과가 규칙 재현 실험임을 명시한다.
- 모델 메타데이터에 과제, 공간 단위, 시간 모드, 라벨 기준 분포, 특징·자료 버전, 학습 종료 시점, 사용한 근거 프로파일을 저장한다.
- 모델 저장 경로는 기존 활동 모델과 분리한다. 자동 활성화하지 않고 지원하지 않는 단위·시점에는 적용하지 않는다.

## 평가와 실행 인터페이스

- 기본 시간 분리는 학습 2025년 10월까지 / 검증 11월 / 테스트 12월이다. 조건에 맞는 양·음성 표본이 없으면 분리를 임의 변경하거나 라벨을 채우지 않고 학습 불가로 보고한다.
- 시간 분리는 같은 지역의 이후 월 평가다. 지역 일반화는 시도 모드에서 시도 전체, 나머지 모드에서 시군구 전체를 분리한 별도 평가로 다룬다. 같은 시군구의 동이 양쪽에 섞이지 않도록 한다.
- 반복 월·성·연령 행 수와 독립 지역 수를 함께 보고한다. 시도 통계를 복제한 행을 추가 독립 표본으로 세지 않는다.
- 평가 항목은 PR-AUC(AP), 정밀도·재현율, 상위 K 적중률, 라벨 적용률·보류율, 연령·성·지역별 표본 수, 라벨 규칙과 모델의 불일치 사례다.
- 약한 라벨 일치도와 독립 확인 라벨 성능을 별도 출력한다. 독립 정답이 없으면 실제 고립 판정 성능은 미평가로 남긴다.
- 제안 CLI: `structural`, `cohorts`, `readiness`, `label --task isolation`, `train --task isolation`, `evaluate --task isolation`. 기존 명령의 기본 동작은 보존한다.
- 새 산출물은 `artifacts/isolation/` 아래 `structural`, `cohorts`, `readiness.json`, `labels`, `label_reference.json`, `models`, `evaluation.json`으로 분리한다.

## 검증 기준

1. 파일명이 시군구여도 내용이 시도뿐이면 지역 단위 불일치로 탐지한다.
2. 소계 중복, 동명이인 행정구역, 합계 불일치와 '-'를 점검한다. 주민등록세대수를 일반가구 분모로 사용하지 않는다.
3. 동·시군구·시도, 60세 이상·65세 이상·20세 미만의 불일치를 묵시적으로 변환하지 않는다.
4. 고독사 수치를 변경해도 라벨·모델 입력은 바뀌지 않고 배경 설명만 바뀐다.
5. 카드 부재·구조 근거 부재·낮은 관측 커버리지가 음성 라벨로 바뀌지 않는다.
6. 평가 월의 값 변경이 학습용 기준 분포·스케일러·모델에 영향을 주지 않는다.
7. 표본 부족 시 학습 중단 사유를 보고하고 기존 활동 모델·검토 기록을 보존한다.
8. 독립 평가 정답이 없으면 실제 고립 판정 정확도를 출력하지 않는다.

## 구현 순서

구조 자료 정규화·공간 좌표 감사 → 서울·강원 소지역 선택 → 공간/연령/시간 정합화 → 라벨·검토 저장 → 준비 조건 충족 시 학습·평가 → 대시보드와 Agent 연결 순서로 진행한다. 시군구·행정동 자료가 없더라도 현재 시도 실험은 수행할 수 있다. 다만 양성·음성 라벨이 모두 있어야 분류 모델을 학습한다.
