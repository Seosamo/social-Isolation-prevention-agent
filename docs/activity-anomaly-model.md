# 서울·강원 활동 위축 이상 탐지

현재 운영 선택은 `IF_F2`입니다. [F2 실행 안내](f2-deployment.md)를 참고하세요. 아래 결과와 6개 입력 설명은 보존된 `IF_BASELINE`에 해당합니다.

정답 라벨이 없는 현재 자료에 맞춰 기본 학습 방법을 Isolation Forest로 전환했다. 대상은 서울·강원 관측 소지역이며, 결과는 고립 여부나 확률이 아닌 **활동 패턴이 학습 분포에서 이례적이면서 감소 근거가 있는 후보**다.

## 모델과 후보 선정

- 관측 행: 소지역 × 성별 × 연령 × 월. 동일 소지역의 반복 행은 독립 지역 수나 사람 수가 아니다.
- 입력 6개: 현재·직전 집단 유동 감소율, 현재·직전 낮 활동 감소율, 현재·직전 주말 활동 감소율.
- 지역 코드·성별·연령 식별자, 원본 유동 규모, 고립 의심 라벨, 구조 통계, 고독사 수치는 Isolation Forest 입력에서 제외한다.
- 지역·성·연령별 중앙값과 IQR로 활동 변화율을 정규화한다. 정규화 기준과 소량 유동 제외 기준은 학습 월에서만 적합하고 이후 월에는 고정한다.
- 두 연속 비교의 품질이 정상이고 입력 6개가 모두 유효해야 한다. 기준 유동량이 학습 집단의 하위 10% 기준 또는 1 미만이면 점수를 보류한다. 없는 활동을 0으로 채워 이상을 만들지 않는다.
- 기본 모델은 트리 200개, seed 42, `contamination=auto`다. 모델의 기본 이진 예측 대신 `-score_samples`를 이상 원점수로 사용한다.
- 이상 후보 경계는 학습 원점수의 95% 분위수로 고정한다. 이는 실제 이상 비율이 5%라는 가정이나 검증된 위험 임계값이 아니다. 이후 월마다 상위 5%를 강제로 뽑지 않는다.
- 위 경계를 넘으면서 **현재 집단 유동이 10% 이상 감소하고 낮 또는 주말 활동도 감소**해야 공개 후보가 된다. 증가 방향의 이상은 후보에서 제외한다.
- 두 연속 20% 감소 여부는 별도 근거로 표시한다. 현재 후보는 기존의 A·S·B 양성 라벨과 다른 선정 기준이다. 일시적 감소나 증가 이후 반락도 포함될 수 있다.
- 백분위는 학습 점수 분포 대비 위치다. 100점은 학습 표본의 최대 이상 점수 이상이라는 뜻이며 고립 확률 100%가 아니다. 동률 후보는 원점수로 정렬한다.
- 시도 1인가구 구성비는 후보 설명의 배경으로만 연결한다. 소지역에서 직접 측정한 구조적 취약성처럼 취급하지 않는다. 10대의 구조 맥락이 없어도 활동 이상 분석은 가능하다.

## 실제 학습 결과

2026-10-20 실제 정제 자료로 학습했다.

| 항목 | 결과 |
| --- | --- |
| 학습 월 | 2025년 10월 |
| 학습 관측 행 | 29,966행 |
| 학습 고유 소지역 | 2,651개 |
| 점수 산출 월 | 2025년 11월·12월 |
| 지역 범위 | 서울·강원 |

7~9월은 필요한 비교 이력이 부족하다. 지역 안의 여러 소지역을 학습 표본으로 쓰기 때문에 시도 집계 18행에 한정됐던 분류 실험과 표본 수가 다르다. 학습이 한 달이므로 평소의 시계열 계절성을 배운 모델은 아니며, 학습 월의 단면적 활동 분포에 비춰 이후 패턴을 비교한다.

| 월 | 지역 | 점수 산출 행 | 위축 이상 후보 행 | 후보 고유 소지역 |
| --- | --- | --- | --- | --- |
| 11월 | 서울 | 21,851 | 47 | 13 |
| 11월 | 강원 | 7,780 | 388 | 50 |
| 12월 | 서울 | 21,942 | 220 | 65 |
| 12월 | 강원 | 7,794 | 690 | 91 |

여러 성·연령에서 같은 소지역이 후보가 될 수 있으므로 행 수와 소지역 수를 함께 보고한다. 위 숫자는 고립 인원이나 실제 고립 지역 수가 아니다.

## 평가와 한계

- seed 43·44로 재학습했을 때, 월·지역별 상위 최대 20개 고유 소지역과 기본 모델 후보의 Jaccard 유사도는 약 0.67~0.92였다. 이는 순위 재현성 점검이며 실제 고립 탐지 정확도가 아니다.
- 학습 점수 90%·95%·97.5% 분위수를 각각 적용한 후보 수를 함께 기록했다. 예를 들어 서울 12월 후보 소지역은 178·65·18개로 달라졌다. 단일 후보 수를 객관적으로 정해진 고립 규모로 해석하면 안 된다. 기본 95%를 테스트 결과에 맞춰 변경하지 않았다.
- 단순 유동 감소율 상위 후보와도 비교했다. 상위 소지역 집합의 Jaccard는 약 0.21~0.38이었다. 다른 패턴을 찾는다는 의미이지 모델이 더 정확하다는 증거는 아니다.
- 11월에도 비지도 후보는 존재한다. 기존 양성 라벨이 필요하지 않기 때문이다. 기존 규칙 분류와 후보 정의가 달라졌다는 점을 명시해야 한다.
- 양성·음성 외부 정답이 없어 정확도·재현율·PR-AUC·고립 확률을 평가하거나 주장하지 않는다. 현재 산출물은 근거 조회와 후속 확인의 우선순위다.
- 시도·소지역의 관측 범위에 한정한다. 전국 또는 시도 전체를 대표하는 표본이라고 보장하지 않는다. 원본 좌표계의 미확인 측지계와 두 UTM-K 후보 합의 매핑이라는 한계도 유지된다.

## 실행법

```powershell
# 기본 비지도 모드: 구조 배경 정제 → 소지역 특징 → 학습 → 이후 월 점수·후보·진단
.venv/Scripts/python.exe -B -m activity_agent run-isolation
.venv/Scripts/python.exe -B -m activity_agent readiness
.venv/Scripts/python.exe -B -m activity_agent evaluate --task isolation
.venv/Scripts/python.exe -B -m activity_agent ask --task isolation --backend local "2025년 12월 강원 50대 남성 활동 이상 근거"
.venv/Scripts/python.exe -B -m activity_agent dashboard
```

`train --task isolation`은 라벨 없이 모델을 학습한다. `detect --task isolation`은 저장 모델로 점수를 재산출한다. 학습 종료 월 이전에는 후보 점수를 공개하지 않고, 학습 범위 밖 지역·미지원 집단·품질 불충분·소량 유동은 보류한다. 설정이나 지역 범위가 모델과 달라지면 재학습을 요구한다. 모델 pickle은 로컬에서 생성한 신뢰할 수 있는 파일만 읽어야 한다.

결과는 `artifacts/isolation/anomaly/` 아래에 저장한다.

- `activity_agent/model/isolation_forest.pkl`, `.json` (프로젝트 루트 기준): 운영 모델, 학습 정규화·유동량 기준, 점수 경계와 버전. Git에 포함하며 학습·추론 모두 이 경로를 사용합니다. 탐지 결과는 기존 artifacts 경로를 유지합니다.
- `detections.parquet`: 모든 관측의 점수·보류 사유·위축 근거와 시도 맥락.
- `candidates.csv`: 이후 월의 위축 이상 후보.
- `candidates.html`: 소지역별 가장 높은 이상 점수 관측을 표시한 독립 HTML 차트.
- `readiness.json`: 비지도 학습 완료 상태. 과거 지도학습의 `isolation/readiness.json`과 별도다.
- `evaluation.json`: 월·지역별 후보 분포, seed 안정성, 점수 경계 민감도, 단순 감소율 비교.

대시보드의 고립 의심 과제는 현재 비지도 모드에서는 활동 위축 이상 탐색 화면을 표시한다. 구조 통계는 설명으로만 제공하고, 질의 답변도 확률 대신 이상 백분위와 실제 감소 근거를 제시한다. 지도학습 실험은 `isolation.method=supervised`로 전환하면 유지된 기존 흐름을 사용할 수 있다.
